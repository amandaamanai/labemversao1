# Site do LABEM UFCG

Site estático. Edite `data/site.json` para mudar conteúdos e `assets/style.css` para o visual.

Publicar: crie o repositório no GitHub, envie os arquivos para a branch `main`, vá em Settings > Pages e escolha "GitHub Actions" como fonte. Cada push em `main` publica de novo.

Testar localmente: `python3 -m http.server` e abra http://localhost:8000.
